# Мультикейс — тренажёр

Тренажёр по ситуационным задачам (кейсам) «Лечебное дело ПСА, 2026»: 44 кейса, 528 вопросов с верными ответами и обоснованиями.

Работает прямо в браузере, без установки: откройте `index.html` или страницу GitHub Pages.

## Что умеет

- **Поиск ответа** — по тексту вопроса, вариантам ответа и по «Ситуации» из условия задачи. Достаточно нескольких слов или их начала, порядок не важен.
- **Кейсы** — список всех кейсов с поиском по названию и ситуации; каждый можно решать как на экзамене или сразу посмотреть ответы.
- **Вопросы подряд** — тренировка по всем вопросам или только по тем, где были ошибки.
- **Статистика** — результаты хранятся в браузере на вашем устройстве.
